# Supply Chain & Delivery Performance Analysis

## Project Overview
This project analyzes supply chain delivery performance, shipping efficiency, sales, and profitability using Python, SQL, and Power BI.

## Objectives
- Analyze late-delivery rates across shipping modes and markets.
- Compare actual and scheduled shipping times.
- Evaluate sales and profit performance.
- Identify patterns that may help improve delivery operations.

## Tools
- **Python:** Data cleaning and exploratory analysis
- **MySQL:** SQL queries and data analysis
- **Power BI:** Interactive dashboard and visualization
- **GitHub:** Project documentation and version control

## Key Findings
- **Overall late-delivery rate:** 54.83%
- **Highest late-delivery rate by shipping mode:** First Class (95.32%)
- **Lowest late-delivery rate by shipping mode:** Standard Class (38.07%)
- **Largest average shipping-time gap:** Second Class (1.99 days)
- **Highest sales by market:** Europe

## Project Structure
- `data/` — Cleaned dataset
- `sql/` — SQL analysis queries
- `dashboard/` — Power BI report and preview image
